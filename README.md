# There's nothing to read

A globe for people who want to wander into books.

Spin it, pick a country, and the literature from that place opens up: novels, poetry, memoirs, and the genres that grew there. Covers sit together as one field. The book under your hand swells. Click it to read where it came from, who wrote it, and why it matters there.

Live at [nothing.nebiyu.et](https://nothing.nebiyu.et).

## Run it

```bash
pnpm install
pnpm dev
```

Then open [localhost:3000](http://localhost:3000).
